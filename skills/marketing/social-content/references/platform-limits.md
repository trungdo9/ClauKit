# Platform Limits Reference

Character counts, hashtag caps, and truncation points per platform.

> **Verify before relying on it.** Every number here is a platform product decision that changes without notice; the values below are what the upstream source recorded in 2025 (including the TikTok 5-hashtag cap it dates to August 2025). Use them to draft, then confirm against the platform's current docs or composer before publishing anything where an overrun would break the post.

---

## Instagram

| Element | Limit |
|---------|-------|
| Max hashtags | 5 |
| Recommended hashtags | 3-5 |
| Max caption chars | 2,200 |
| Visible before "more" | ~125 chars |

## Facebook

| Element | Limit |
|---------|-------|
| Max hashtags | No stated limit |
| Recommended hashtags | 1-2 |
| Max post chars | 63,206 |
| Best for engagement | 40-80 chars |

## TikTok

| Element | Limit |
|---------|-------|
| Max hashtags | 5 (since August 2025) |
| Recommended hashtags | 3-5 |
| Max caption chars | 4,000 |
| Visible before "more" | ~150 chars |

## LinkedIn

| Element | Limit |
|---------|-------|
| Max hashtags | No stated limit |
| Recommended hashtags | 3-5 |
| Max post chars | 3,000 |
| Visible before "more" | ~210 chars |

## Twitter/X

| Element | Limit |
|---------|-------|
| Max hashtags | No stated limit |
| Recommended hashtags | 1-2 |
| Max post chars | 280 standard / 25,000 paid tier |
| Visible before "more" | Full post at 280 |

## YouTube

| Element | Limit |
|---------|-------|
| Max hashtags | 15 — exceeding it causes YouTube to ignore ALL hashtags |
| Recommended hashtags | 3-5 (1-5 for Shorts) |
| Max title chars | 100 (truncates ~70) |
| Max description chars | 5,000 |
| Visible before "Show more" | ~100 chars |

> The first 3 hashtags in the description surface above the title as clickable links.

## Pinterest

| Element | Limit |
|---------|-------|
| Max hashtags | 20 per pin |
| Recommended hashtags | 2-5 |
| Max pin title chars | 100 |
| Max description chars | 500 |
| Visible before "More" | ~50 chars (desktop) |

> Pinterest has deprioritized hashtags. Write keywords as natural sentences in the description instead.

## Threads (Meta)

| Element | Limit |
|---------|-------|
| Max hashtags | 1 topic tag per post |
| Recommended hashtags | 1 |
| Max post chars | 500 |
| Max with text attachment | 10,500 (500 + 10,000 expandable) |
| Visible without expanding | First ~1-2 lines |

> Threads is not hashtag-driven — the feed mixes followed accounts with recommendations.

---

## Rules that outlast the numbers

- **Hashtags count against character limits** on every platform.
- **Front-load the message** before the truncation point — the visible-before-"more" figure is the real headline length.
- On Instagram and TikTok, a few precise hashtags outperform hashtag-stuffing.
- On LinkedIn, hashtags at the end of the post perform better than inline.
- On Facebook, hashtags barely affect reach — use sparingly.
- When a draft is near a cap, cut the post, don't cut the hook.
