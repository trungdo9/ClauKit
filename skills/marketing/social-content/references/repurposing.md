# Repurposing: Long-Form to Platform-Native

The best social content is not written from scratch — it is extracted from something longer and rebuilt for each platform. This file covers the source types beyond blog articles; the article-to-social recipe (the routed job from the SEO pipeline) lives in SKILL.md.

Boundary: [[content-strategy]] decides *which* flagship pieces get atomized and how the distribution plan is sequenced (its `references/content-distribution.md` holds the ORB funnel and per-flagship atomization checklist). This file is the execution — what the atoms are, how to cut them, and what each platform gets.

---

## Content Atoms

An atom is a self-contained moment that works with none of its original context. Extraction is a search for atoms, not a summarization pass.

| Atom type | What to look for | Best platform |
|-----------|------------------|---------------|
| Quotable moment | A bold claim, hot take, or memorable line (15-60 sec) | X, LinkedIn, TikTok |
| Story arc | Complete mini-story: setup, conflict, resolution (60-90 sec) | Reels, TikTok, Shorts |
| Tactical tip | One specific how-to or framework, explained cleanly (30-60 sec) | LinkedIn, Shorts |
| Contrarian take | An opinion that will draw disagreement | X, LinkedIn |
| Data callout | A surprising number or finding — must be real and yours or cited | LinkedIn carousel, X |
| Behind-the-scenes | Authentic, unpolished process moments | Stories, TikTok |

The test for every atom: **does it make sense to someone who never saw the source?** If it needs "as I mentioned earlier", it is not an atom yet — write the missing setup into the caption.

## Podcast or Long Video

**Workflow**
1. **Get the transcript** — the host's transcription, or a transcription tool.
2. **Mark timestamps** — flag the 5-10 strongest moments while scanning.
3. **Cut clips** — one clip per moment; vertical crop, speaker centred.
4. **Write standalone captions** — each clip needs its own context, hook, and CTA.
5. **Add subtitles** — most social video is watched muted; see [short-form-video.md](short-form-video.md).
6. **Schedule across 1-2 weeks** — one episode is a fortnight of posts, not one dump.

**Per episode, target:**
- 3-5 clips or audiograms (15-60 sec) for Reels/TikTok/Shorts
- 1-2 LinkedIn text posts from the strongest insights
- 1 X thread of takeaways
- 1 carousel of the main framework or list
- 1 newsletter section or blog post from the best segment

## Webinar or Live Event

| Extract | Format |
|---------|--------|
| Key slides with commentary | LinkedIn carousel / document post |
| Q&A highlights | X thread |
| Speaker quotes | Quote graphics (Instagram, LinkedIn) |
| Poll results and audience reactions | Engagement post — ask the same question to the feed |
| Recording | Short clips for Reels/TikTok/Shorts |

Q&A is usually the highest-value cut: the questions are the audience's real objections in their own words, which is also hook material for [[copywriting]] and [[ad-creative]].

## Newsletter

| Extract | Format |
|---------|--------|
| Main insight | LinkedIn post |
| Curated links with commentary | X thread |
| A data point or chart | Quote graphic / carousel slide |
| The hot take | X post, LinkedIn post |

Newsletters repurpose cleanly because they are already written in voice. Cut the greeting, cut the sign-off, keep the argument.

## The Repurposing Loop

1. **Ship the flagship** (article, video, podcast, webinar, newsletter).
2. **Extract 5-10 atoms.**
3. **Adapt per platform** — format, length, tone, link handling.
4. **Write standalone captions** — every post must work alone.
5. **Spread across the week** — never publish all cuts on one day.
6. **Reshare evergreen** — a strong atom can run again in 3-6 months, rewritten with a new hook.

**Never** cross-post the identical text to every platform. The same idea, rewritten to each platform's native shape, is repurposing; a copy-paste is the reason cross-posted content underperforms.

---

## Quality Gates

- Every claim, number, and quote traces back to the source piece — no numbers invented in the cut.
- Voice matches `plans/marketing-context.md`, including the forbidden-word list.
- Each post carries exactly one CTA.
- Link handling per platform: LinkedIn link in the first comment, Instagram link in bio or Stories, X link in the final post of the thread.
- The atom log records which atoms are used and which are still unspent — the same flagship should not be re-cut from zero next quarter.
