# The REACH framework — play the surfaces, not the dead feed

Facebook is no longer a Page-broadcast feed. It is an **AI discovery engine plus a community platform**.
Stop spraying Page posts at followers (~1.65% reach — estimate, re-verify quarterly) and play the **three
surfaces**: Reels for discovery, Feed for depth, Groups for community.

## R — Reels for discovery

- Reels are the **unconnected-discovery** engine, pushed to non-followers **by content category** (NLP
  reads captions and transcripts). Page Reels commonly out-reach Page posts several-fold.
- Win the **first 3 seconds**, then **retention** and **completion**. All videos are Reels now — design
  vertical and native. Script craft → [[social-content]].

## E — Engage the first hour

- **Velocity in the first 30–60 minutes** decides reach. Post inside the audience's active window and
  **reply to every comment** fast.
- Optimize for **saves, shares, and meaningful comments** — not likes.
- The cadence that makes this survivable → [[engagement-routine]].

## A — Anchor ~2 themes

- The algorithm tags the account from its **last 9–12 posts**. **Focus ~2 core themes** so the AI can
  match the Page to an audience with confidence.
- Use **social-SEO keywords** naturally — Facebook reads the text. The keyword layer → [[hashtag-strategy]].
- Pick **one clear viewer**. An occasional off-topic team moment is fine.

## C — Community in Groups

- **Groups are the goldmine** (20–40% member reach versus 1–6% for Pages; Meta favors them). Start one, or
  participate genuinely in niche Groups. Group posts rank higher on the community signal.
- Community is **human-run and in-app** — never auto-blasted. The full Groups strategy → [[facebook-groups]];
  the day-to-day discipline → [[engagement-routine]].

## H — Hold trust in Feed, handle links natively

- **Feed is connected depth and trust:** photos (highest feed engagement), carousels (storytelling), longer
  **3–8 minute video** (time spent).
- **Pair a Reel (discovery) with a Feed post (depth)** on the same theme.
- **Links perform worst — put the link in the first comment**, or use a native Shop.
- **No engagement bait.** Lean on the authenticity premium: behind-the-scenes, founder-led, real people
  doing real work.

## The Facebook brief a request should fill

```
SURFACES: Reel (discovery) + Feed post (depth) per theme; Group plan (human-run)
THEMES:   ~2 core themes; one clear viewer; social-SEO keywords in captions
REEL:     vertical, first-3-seconds hook, built for retention/completion
FEED:     photo / carousel / long video; save- and share-worthy; link in the FIRST COMMENT
ENGAGE:   post inside the active window; a named human replies to every comment in the first hour
MEASURE:  native Meta Insights (reach, saves, shares, watch time) per surface; snapshot weekly (~90-day retention)
TRACKING: every outbound link carries UTM, or the post is unmeasurable
```
