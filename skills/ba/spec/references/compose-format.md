# Compose format — D-4, binding

`compose` (`node .claude/scripts/ba/traceability.cjs compose <project-dir>`, wired to
`/ba:spec compose`) renders each `FR` into exactly this block. Copy verbatim — this is the
contract `.claude/scripts/ba/lib/spine-compose.cjs` implements, not a style suggestion:

```markdown
## FR-012 — Duyệt đơn hoàn tiền
**Actor:** CSKH   **Precondition:** đơn ở TRẢ_HÀNG
**source:** src/order/refund.service.ts:88   **confidence:** high

Given đơn có trạng thái TRẢ_HÀNG
When CSKH bấm Duyệt hoàn
Then hệ thống ghi REFUND_APPROVED
```

`NFR`/`UC`/`US` render the same two-line meta head (`## <id> — <title>` then
`**source:** … **confidence:** …`) followed by the entity's own body — no `Actor`/`Precondition`
line, that pair is FR-only. `TC` renders `## <id> — <title>` plus body only, no meta line: it
carries `parents` naming the `AC` it exercises instead, and doubling the source/confidence
bookkeeping across `AC`+`TC` would double-count against the exit gate's
`FR+NFR+UC+US == source-line count` equality.

## Document order

`# SRS-001 — <title>` → `## Phạm vi` (the `SRS-001` entity's own body) → `FR` (ascending) → `NFR`
→ `UC` → `US` **with its `AC`s nested beneath it** → `TC`. Each `AC` renders as
`### AC-007.1 — <title>` under its parent `US`.

## Every rendered `FR` block carries all five `/ck:cook` Stage-0 items

Because `--from-plan` extracts them from this file and `[ASSUMED]`-logs whatever is missing.
**These four lines render on `FR` blocks only** — `US`/`NFR`/`UC` carry the two-line meta head
above, nothing more; nesting them on every kind would make the label counts stop equalling the FR
count, which is exactly what Gate 4 checks.

| item | rendered as |
|---|---|
| expected output | the `## FR-### — <title>` heading + body |
| acceptance criteria | nested `### AC-###.#` Given/When/Then blocks, under the FR's `US` children |
| scope boundary | `**Out of scope:**` — the FR's own `out_of_scope`, else inherited from its parent `EPIC`'s |
| constraints | `**Constraints:**` — the `NFR-*` ids+titles reachable from the same `EPIC` as the FR, comma-joined, or the literal `Không có` when none exist |
| touchpoints | `**Touches:**` — `source:` when it is a real `file:line` (not `doc:…`, not `[UNVERIFIED]`), else `touches:`, else the literal `[UNKNOWN]` |

Three of the five were already there (heading+body, AC, source-derived touch); the emphasis is
that **compose must not drop them into prose** — a bolded labelled line (`**Out of scope:**
<text>`) is the difference between a satisfied `/ck:cook` Stage-0 item and an `[ASSUMED]` one.

## Header, and no timestamp

The rendered file opens with a comment stating it is generated by `/ba:spec compose` and must not
be hand-edited — a reader who receives the `.md` by email needs to know where corrections go
(edit the entity, re-run `compose`). It carries **no generation timestamp anywhere in the body**:
the deliverable must be byte-stable over an unchanged entity tree, and generation metadata
(`generated`, the ISO timestamp) lives in `traceability.derived.json` instead — see
`.claude/scripts/ba/lib/spine-compose.cjs`.
