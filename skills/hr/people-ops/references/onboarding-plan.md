# Onboarding plan template

Used by `/hr:people onboard`. Save to `plans/hr/<slug>/onboarding-plan.md`. Roles or pseudonyms only
(`New hire A`, `Hiring manager`) — names, IDs and personal documents stay in the HRIS (hr-rules § 3).

```markdown
# Onboarding plan: [role / cohort] — [start date or window]

- Jurisdiction: [country, state/province]   Work pattern: [on-site / remote / hybrid]
- Population: [single hire / cohort of N] — role family: [ ]   Level: [ ]
- Owners: HR ops [role] · Hiring manager [role] · IT [role] · Buddy [role] · HRBP [role]
- Source of truth for status: [HRIS / tracker link — no personal data in this file]

## 1. Role outcomes (written by the hiring manager before day 1)
- By day 30 the new hire can: [explain priorities, stakeholders, success measures]
- By day 60 the new hire can: [own these core tasks with support]
- By day 90 the new hire can: [deliver these outcomes independently]
- Success measures: [observable, job-related]

## 2. Pre-boarding (offer accepted → day 0)
| # | Task | Trigger | Owner | Due | Done |
|---|---|---|---|---|---|
| 1 | HRIS record created | Offer accepted | People ops | Same business day | [ ] |
| 2 | Equipment + access request raised | HRIS record | People ops | Immediately after #1 | [ ] |
| 3 | Equipment configured, accounts provisioned | Request | IT | [IT lead time] before start | [ ] |
| 4 | Contract, right-to-work, tax/social-insurance registration | Offer accepted | HR ops | [VERIFY: <country> law] | [ ] |
| 5 | Payroll and benefits enrolment instructions sent | HRIS record | HR ops | [enrolment window — VERIFY] | [ ] |
| 6 | Welcome message from the manager | Start date confirmed | Manager | [ ] days before start | [ ] |
| 7 | Day-1 schedule and first-week calendar sent | | Manager / HR | [ ] days before start | [ ] |
| 8 | Buddy named and briefed | | Manager | Before day 1 | [ ] |
| 9 | Workspace or remote kit delivered | | Facilities / IT | Before day 1 | [ ] |
| 10 | Readiness confirmation (equipment, access, schedule) | Business day before start | IT + people ops | End of that day | [ ] |

Pre-boarding forms ask only what the job and the law require. One neutral prompt:
"Is there anything that would help you do your best work from day one?" — no questions about
health, disability, family plans, religion or age. Adjustment requests → hr-employee-relations.

## 3. Day 1
- [ ] Manager welcome first (not only HR)
- [ ] Logistics: where things are, how systems work, who to contact for what
- [ ] Team introductions + relevant cross-functional contacts, each with "why you'll work together"
- [ ] Tools working; first-week plan walked through
- [ ] Buddy meet
- [ ] End-of-day check: "Anything missing or unclear?"

## 4. Week 1
- [ ] Role outcomes and success measures discussed (section 1)
- [ ] Key stakeholder meetings booked with context
- [ ] Weekly 1:1 series booked for the first [ ] weeks
- [ ] Required compliance training assigned (content → hr-learning)
- [ ] First small deliverable agreed

## 5. Days 2–30 / 31–60 / 61–90
| Window | Focus | New hire actions | Manager actions | Buddy |
|---|---|---|---|---|
| 1–30 | Learn workflows, relationships | Shadow, first deliverable, stakeholder map | Weekly 1:1, explain outcomes, early feedback | Weekly contact |
| 31–60 | Own core tasks with support | Own [tasks]; ask for feedback | Structured feedback, remove blockers | As needed |
| 61–90 | Independent execution | Deliver [outcome]; draft development goals | Day-90 review, agree development plan | Close-out chat |

Track-specific additions:
- People manager track: people processes, approval tools, team rituals, manager peer group.
- Remote: scheduled social touchpoints, explicit async norms, visible team rituals.
- Relocating / international: right-to-work, registration, local orientation → hr-global.

## 6. Check-ins (30 / 60 / 90 — manager AND HR, separately)
Role clarity
- What parts of your role feel clear? What still feels unclear?
Support and tools
- Do you have the access, tools and context you need? Where are you blocked?
Connection
- Which relationships are helping you ramp up? Who else should you meet?
Feedback
- What has gone well? What should we adjust for the next 30 days?
Agreements
- New hire next steps: [ ]   Manager next steps: [ ]   Follow-up date: [ ]

Notes from HR check-ins stay confidential to HR unless the new hire agrees to share them.

## 7. Day-90 handoff
- [ ] Day-90 review held (probation rules if any: [VERIFY: contract + <country> law])
- [ ] Development plan agreed → hr-performance
- [ ] Onboarding feedback captured (aggregate only)

## 9. Measures (baseline first — no external benchmark without a source)
```
