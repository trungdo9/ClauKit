# Intake brief and JD templates

Companion to the `hr-recruiting` skill file (actions `intake`, `jd`). Roles and pseudonyms only — no
candidate or employee names (hr-rules § 3). Pay figures come from the band owned by `hr-rewards`, never
from memory (hr-rules § 4).

## Inclusive-wording checklist

| Replace / remove | Why | Use instead |
|---|---|---|
| he / she | Gendered | you, the person in this role |
| rockstar, ninja, guru, hero | Insider jargon, skews pool | specific skill or outcome |
| digital native, young, energetic team, recent graduate (unless a graduate scheme) | Age proxy | name the skill |
| native speaker | Origin proxy | fluent / professional-level [language] |
| must be able to lift / stand (if not essential) | Disability proxy | only if an essential function |
| aggressive, dominant, crush it, work hard play hard | Exclusionary bravado | direct, decisive, high ownership |
| X+ years of Y | Tenure proxy | what they must be able to do |
| degree required (work doesn't need it) | Access proxy | or equivalent experience — or drop |
| culture fit | Undefined, similarity bias | the named behaviour |
| internal acronyms, grade codes | Unreadable outside | plain words |

## Pre-posting check

- [ ] Every must-have traces to a task or outcome in the intake brief
- [ ] No more must-haves than the role truly needs on day one
- [ ] No banned topic, protected-characteristic proxy, or unjustified credential
- [ ] Pay range and pay-history rules checked for each posting jurisdiction [VERIFY: local law]
- [ ] Title matches market usage; reporting line and team size accurate
- [ ] Adjustment request route stated
- [ ] Readable on a phone (short paragraphs, bullets)
- [ ] Hiring manager sign-off recorded
