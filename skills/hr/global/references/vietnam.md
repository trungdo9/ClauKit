## 2. Contracts and probation

- **Form:** written (or recognised electronic) contract for terms above a minimum duration `[VERIFY: Labor Code Art. 14 — threshold]`; sign on or before day one. Verbal arrangements for anything longer are non-compliant.
- **Language:** Vietnamese or bilingual is standard practice; confirm the rule and which version governs `[VERIFY: Labor Code 2019 / Decree 145/2020 — contract language]`.
- **Types:** indefinite-term and definite-term `[VERIFY: Labor Code Art. 20 — maximum definite term, number of renewals before conversion, exceptions]`.
- **Mandatory content:** `[VERIFY: Labor Code Art. 21]`. Contract appendices for changes `[VERIFY: Art. 22]`.
- **Probation:** maximum length by job category, salary floor during probation, no probation for very short contracts, notice-free ending during probation `[VERIFY: Labor Code Arts. 24–27]`.
- **Internal labour rules** (nội quy lao động): written; registration required above an employee-count threshold `[VERIFY: Labor Code Arts. 118–119 — threshold, filing deadline]`. Discipline is only possible for breaches the rules define.

## 5. Trade union and representation

- **Trade-union fee:** employers pay a fee calculated on the SI salary fund, whether or not a grassroots union exists `[VERIFY: Law on Trade Union No. 50/2024/QH15; union-finance decree — rate and basis]`. Member dues paid by employees are separate.
- **Representation:** the 2019 Code recognises grassroots employee representative organisations beyond the union `[VERIFY: Labor Code — chapter on employee representative organisations]`.
- **Workplace dialogue:** periodic and on-demand dialogue obligations `[VERIFY: Labor Code Art. 63; Decree 145/2020 — frequency]`.
- **Collective labour agreement:** negotiation, content, registration `[VERIFY: Labor Code Chapter V — collective bargaining and agreements]`.
- **Consultation:** representatives must be consulted on internal rules, wage scales, discipline and restructuring `[VERIFY: relevant articles]`.

## 6. Foreign employees

Sequence (owner: HR + immigration agent + counsel):
1. **Labour-demand explanation / approval** for using foreign workers, incl. any prior local recruitment notice `[VERIFY: Decree 152/2020 as amended — steps, lead time; possible successor: Decree 219/2025 (152/2020) — confirm]`.
2. **Documents:** health certificate, criminal-record check, degree and experience proof, passport — legalised and translated `[VERIFY: list + validity windows]`.
3. **Work permit** issued, or **exemption certificate** where a category applies `[VERIFY: Labor Code Art. 154 + decree — exemption categories]`. Permit validity and renewal `[VERIFY: Labor Code Art. 155]`.
4. **Work visa → Temporary Residence Card (TRC)** `[VERIFY: Entry/Residence Law — categories, validity]`. Working on a business or tourist visa is not a substitute.
5. **Contract** signed after the permit; **SI enrolment** and **PIT registration** for the foreign employee `[VERIFY: SI coverage rule]`.
6. **Calendar** expiry dates for permit, TRC, passport; start renewals well ahead `[VERIFY: renewal lead time]`.
Plan the whole chain with the agent before promising a start date. Case handling → `hr-employee-relations`.

## 7. Discipline and termination

**Discipline** — procedure errors void the sanction regardless of merit.
- Forms of sanction `[VERIFY: Labor Code Art. 124]`; dismissal (sa thải) only on listed grounds `[VERIFY: Art. 125]`.
- Procedure: breach defined in registered internal rules; employer proves fault; written notice of the meeting to the employee and the representative organisation in advance `[VERIFY: Decree 145/2020 Art. 70 — notice period]`; meeting with the employee (and representative) present; minutes signed; written decision within the limitation period `[VERIFY: Labor Code Arts. 122–123]`.
- Prohibited: monetary fines or pay deductions as discipline, discipline for an act not in the rules `[VERIFY: Labor Code Art. 127]`; no discipline during protected periods (e.g. leave, sickness, pregnancy-related) `[VERIFY: Art. 122]`.

**Termination routes**
| Route | Check |
|---|---|
| Contract expiry | Notice and conversion rules `[VERIFY: Labor Code Arts. 20, 34, 45]` |
| Mutual agreement | Written; terms recorded `[VERIFY: Art. 34]` |
| Employee resignation | Notice by contract type and exceptions `[VERIFY: Art. 35]` |
| Employer unilateral (e.g. repeated failure to complete work per the employer's criteria, prolonged illness, force majeure) | Ground must match the list; notice by contract type `[VERIFY: Art. 36]` |
| Restructuring / economic reasons | Labour usage plan, representative consultation, authority notice `[VERIFY: Arts. 42–44]` |
| Dismissal (disciplinary) | Section above `[VERIFY: Art. 125]` |

**Payments and paperwork:** severance allowance (trợ cấp thôi việc) vs job-loss allowance (trợ cấp mất việc làm) — eligibility and formula `[VERIFY: Labor Code Arts. 46–47]`; final settlement deadline `[VERIFY: Art. 48]`; return of SI records and documents `[VERIFY: Art. 48]`. Unlawful termination exposes the employer to reinstatement, back pay and compensation `[VERIFY: Art. 41]`.
Every discipline or termination ends with: *review with qualified employment counsel (or the relevant authority) before acting.* (hr-rules § 2).

## 9. Culture notes for managers (hypotheses — check with local staff)

| Pattern often reported | What it means for practice |
|---|---|
| Respect for hierarchy and seniority | Make it explicit that challenge is wanted; ask juniors first in meetings |
| Saving face; disagreement expressed indirectly | Critical feedback in private 1:1s; use anonymous surveys and skip-levels |
| "Yes" may mean "I heard you" | Confirm actions and owners in writing; ask open questions ("what could block this?") |
| Relationship before task | Invest in rapport; local leaders front important messages |
| Tet as the year's focal point | Plan hiring, releases and reviews around it; expect job moves after Tet bonuses are paid; communicate bonus policy early |
| Family obligations weigh heavily | Flexible leave handling builds trust |
| Clear pay breakdown expected | Payslips showing base, allowances, bonuses, deductions |
