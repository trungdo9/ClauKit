# Call Coaching Debrief — Template

Template for [discovery](../SKILL.md) § Call coaching. Roles and handles only — no names, no recording URLs in committed files (`.claude/workflows/automation-rules.md` R4).

```markdown
# Call Coaching: [rep-handle] — [date]

## Call
- Account: [account-slug]
- Type: [Discovery / Demo / Negotiation / Executive]
- Buyer attendees (roles): [e.g. VP Ops, IT lead]
- Duration: [min]
- Recording: [reference ID in call tool]

## What went well
- [mm:ss] — [specific moment] — [why it worked]

## One coaching opportunity
- Moment: [mm:ss] — [what the buyer said or did]
- What happened: [rep's response]
- Try instead: [exact words or approach]
- Why it matters: [what it would have unlocked — which MEDDPICC element or gap]

## Diagnosis
- Gap type: [skill | will | environment]
- Connects to focus area: [from the rep's development plan, if any]

## Practice + follow-up
- Assignment for next call: [one observable behaviour]
- Review date: [date] — [which call will be reviewed]
```

Coaching loop: **observe → ask → suggest → practice**. Describe what you observed, ask what the rep was thinking, suggest one alternative, rehearse it. Praise specific technique, not outcomes.
